## ✨ Features
- **Echo Pulse (V)** — sonar that paints blocks in material colors, with per-stage interference
- **Infection** — five stages from first contact to possession
- **20 infected mobs** across Overworld, Nether, End, Trial Chambers and the oceans
- **Reflectors** — 16 color implants with a two-minute rejection phase
- **Sculk Merchant** — a villager who accepted the sculk

##  Installation
1. Install [NeoForge](https://neoforged.net) for Minecraft 1.21.1
2. Download the latest jar from [Modrinth](https://modrinth.com/mod/sculk-echo)
3. Drop it into your `mods` folder

```bash
